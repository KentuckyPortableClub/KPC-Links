KPC Find a Park 2-fer terminology correction

POTA 2-fer means two distinct US-#### POTA references with overlapping eligible activation area. POTA + WWFF/KFF is not a POTA 2-fer. Historical KFF links now show as WWFF/KFF cross-references; GIS trail proximity is no longer called a possible 2-fer. No POTA/POTA overlap is claimed without verified qualifying references and boundaries.

Upload finder.js, gis-overlays.js and finder.html to your GitHub website root. Other files are included for convenience. Refresh with Ctrl+F5.
