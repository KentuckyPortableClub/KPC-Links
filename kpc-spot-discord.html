How it works: A scheduled GitHub Actions workflow checks the POTA live spot feed about every five minutes. When a new spot for one of these callsigns appears, it posts the callsign, park, frequency, and mode in your Discord channel. The webpage does not need to stay open.

Administrator Setup

One-time GitHub and Discord setup is required before automatic notifications begin.

  1. In your Discord channel, open Edit Channel → Integrations → Webhooks → New Webhook and copy the webhook URL. Keep it private.
  2. On GitHub, open your website repository's Settings → Secrets and variables → Actions → New repository secret.
  3. Name the secret KPC_DISCORD_WEBHOOK and paste the webhook URL as its value.
  4. Upload kpc-spots.html to the repository root and kpc-pota-discord.yml into .github/workflows/.
  5. In GitHub Settings → Actions → General, set workflow permissions to Read and write permissions so the bot can remember spots already sent.
  6. Open Actions → KPC POTA Discord Spotter → Run workflow to test. No Discord message is sent unless a monitored operator has a recent spot.

Note: GitHub's scheduled runs can be delayed; notifications are not guaranteed to arrive at the exact five-minute mark.
