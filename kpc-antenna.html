Linked dipole planner

Tap the bands your linked dipole should cover (it uses the wire adjustment above). Highest band is built and tuned first.

Measure each leg from the center insulator to the middle of the link, and add a few inches at every link and end for connector loops and trimming. Set both legs alike. Start long and trim while watching SWR.

Lengths use the classic formulas — half-wave 468 ÷ MHz feet, quarter-wave 234 ÷ MHz feet — which already allow for typical wire end effects. Real antennas vary with wire, insulation, height and nearby objects, so cut a little long and trim while checking SWR. End-fed half-waves usually need a 49:1 (or 64:1) transformer.
