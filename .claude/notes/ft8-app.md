## LOG STORAGE + SYNC: THE DECISION (Fable, Oct 22 7 AM — everything builds on this, change it only on purpose)
- **One record per contact, the same on phone and PC** (JSON object; ADIF stays the export, never the store). Fields: `id` (stable, never changes: time in base-36 + 8 random characters, made on the device that logged it), `v` (edit count), `u` (last-changed time ms), `d` (1 = taken out of the log: a 'tombstone' kept so the deletion reaches the other device too; dropped after a year), `t` (contact time ms), `call`, `khz`, `band`, `mode`, `rs`, `rr`, `st`, `g`, `name`, `note`, **`refs`** (THEIR park numbers, a list: a 2-fer on their side is two entries; old `ref` = `refs[0]` stays for the screens), **`myrefs`** (MY park numbers, a list: my own 2-fer), `station` (STATION_CALLSIGN: the licence the station runs under, e.g. the club call), `op` (OPERATOR: who is at the key), `ctl` (control operator, only when not the operator: remote / guest pass, Part 97.119 → ADIF APP_KPC_CONTROL_OP), `src` (which device made it).
- **Where it lives:** IndexedDB `kpc-log` (store `qso`, key `id`) on both platforms, loaded into memory at start; the old localStorage list is moved over once (each old contact gets an id made from station+call+minute+band+mode, so the SAME old contact on two devices lands on ONE id and merges). localStorage stays only as a fallback if IndexedDB is missing.
- **Merge rule (no duplicates, no questions):** by `id`; higher `v` wins, tie → later `u` wins; a tombstone beats a live record with a lower `v`. Records with no id (ADIF imports, old files) get the hash id above first, so re-importing the same ADIF twice does nothing.
- **Several operators on one install:** ONE store; every record carries `op`. The LOG screen shows the current operator's contacts; ADIF export is per operator. Operator profiles (`kpcOps`: call, grid, name, macros, CQ word) live in STATION → My station → OPERATORS. Switching operator = switching whose log you see; nothing is copied.
- **ADIF export for a 2-fer on my side:** one record in the store, one ADIF line PER my park (POTA wants a log per park; the file name carries the park). Their 2-fer = SIG_INFO/POTA_REF of the first ref + the rest in APP_KPC_REFS and the COMMENT ('also US-1234').
- **How phone and PC sync:** (1) over the remote link, automatically: on connect both sides send 'everything changed since the last time I saw you' (a watermark per peer) and merge; after that every new or edited record goes across at once. (2) Any time, no link: STATION → Log files → SAVE KPC LOG FILE (.kpclog = the records as JSON) and ADD A KPC LOG FILE on the other device = the same merge. (3) Cloud backup = later, same merge over a file in Drive or on the club's server.
- NOT decided here, on purpose: log per park folder on disk, QRZ/LoTW upload flags per record (Opus adds `up` {qrz, pota, lotw} when step 4 lands; the merge rule covers it).

## REMOTE OPERATION: HOW IT IS BUILT (Fable, Oct 22)
- **Windows app = base station.** It runs a small server on port 8731 (STATION → Remote on the PC: shows its addresses — home WiFi and Tailscale — and a 6-digit PAIR CODE, new each time the PC app starts). The phone types the address + code once; the PC pops 'Phone X wants to pair: APPROVE / NO'; the phone gets a key it keeps. After that CONNECT just works, from home WiFi or from anywhere over Tailscale (the phone tries both addresses; no router port-forwarding; the code is the login on the station side, and the PC can throw a phone out any time (REVOKE)).
- **Over the link:** radio control (band, dial, mode), PTT, TUNE, the FT8 decodes (the PC decodes; the phone sees the lines), two-way sound by WebRTC (RX in the phone's speaker, the phone's mic to the radio on HOLD TO TALK), and the log sync above. Sound and radio stay on the PC; the phone only sends requests.
- **SAFETY (not optional, all on the PC side):** PTT needs a heartbeat from the phone every second — 2.5 s without one, or the link closing, or the PC app losing the phone → PTT OFF and TX stopped (watchdog). TX time limit per press (3 min talk, 20 s TUNE, FT8 = its own slot) → PTT off and a note. Nobody gets in without the pair code + approval; keys are revocable; one phone at a time holds the key (a second one can only watch).
- Guest pass (band edges by licence class, power cap, expiry, revoke, station/op/control-op in the log) = AFTER the basic link is proven on Brandon's rig.
