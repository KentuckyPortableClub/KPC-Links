# OFFICIAL PARK MAPS, STATE BY STATE: where agencies link them (Research desk, chat 8, Oct 27)

Rule from HQ: a map is official because the agency's OWN page links to it, wherever the file lives; no third-party copies. **The 10 states are an ASSUMPTION** (FL, PA, NY, NC, VA, GA, OH, TX, CA, MI; HQ please confirm). I read the page text the search tool gives me; for several pages it shows link LABELS but not the link addresses, so those are marked "harvester must read the hrefs". Grades: A = page/file opened and read; B = surfaced by search, not fully opened.

## Kentucky (the model)
Park page on parks.ky.gov has a "Maps" section; the PDFs sit on kentuckytourism.com. KDFWR WMA maps: https://fw.ky.gov/More/Documents/<Name>WMA_ALL.pdf. Forestry: https://eec.ky.gov/Natural-Resources/Forestry/Documents/<Name>_ALL.pdf.

## Patterns the harvester can rely on
1. Start from each agency's park LIST, open each park page, collect the links in its Maps/Trail-maps section; keep only files the page itself links (the "wherever the file lives" rule).
2. Allowed hosts per agency (a per-agency allow list, as already ruled): floridastateparks.org (+ file host to be read); myfwc.com; pa.gov, dcnr.pa.gov, elibrary.dcnr.pa.gov; parks.ny.gov; ncparks.gov; dcr.virginia.gov (and its mirror dcr.am.virginia.gov to be confirmed); gastateparks.org + gadnrle.org (to be confirmed); ohiodnr.gov, dam.assets.ohio.gov; tpwd.texas.gov; parks.ca.gov; michigan.gov, dnr.state.mi.us.
3. **Third-party copies to reject**: the flbezvotyyjruhqdwgst.supabase.co "park-maps" storage bucket (it mirrors Kentucky, Georgia and other parks' maps), Avenza (an app store, use only as a cross-check), Wikipedia, tourism and camping sites.
4. Geo-referenced PDFs (Florida GeoPDF, Virginia Avenza PDFs) are the most useful for later tools because the map is tied to coordinates; mark them in the data.
5. Wildlife-area maps (state game lands, WMAs) are a SEPARATE agency in every state and I have not mapped them except Florida FWC and Kentucky; they are the second pass.
