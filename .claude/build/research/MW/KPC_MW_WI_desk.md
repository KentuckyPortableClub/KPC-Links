## 4. Tricky land
- **Kettle Moraine** (Northern/Southern Units State Forest) holds SRAs (Mauthe Lake, Long Lake) inside state forest: layered, same agency.
- **Chequamegon-Nicolet NF** vs. WDNR lands (county forests too).
- **County forests** (not state): often "public access" but owned by counties – our list type "county" ask.
- Water: Apostle Islands (NPS), Lake Michigan.
