# US-KY official maps: who runs it (desk, Oct 28 2026)
No map links for Kentucky are in data/parkinfo-web.json (the aggregate found none), so everything below is fresh desk research.

## Desk research Oct 28
- **Fish & Wildlife (KDFWR) WMAs and state-forest hunting areas:** pattern `https://fw.ky.gov/More/Documents/<Name>WMA_ALL.pdf` (also `<Name>WMAall.pdf`, `<name>_all.pdf`; case varies: `kentuckyridgestateforest_all.pdf`) (A, from search results; one opened). Date: printed ON the map. KentuckyLakeWMA_ALL.pdf says publication date 11/18/2016 (A) - so a KY WMA map can be ten years old. Penn Forest/Tradewater map is also mirrored at eec.ky.gov/Natural-Resources/Forestry/Documents/ (B). Rules: KDFWR hunting guide (fw.ky.gov) - page not opened (TO DO).

## Correction from HQ: Kentucky's saved links (data/ky-official-maps.json, 216 places, read from the agency pages 2026-10-27 09:52 UTC; `off` field in kpc-ky-data.json: 192 parks, of which 79 fw.ky.gov, 46 kentuckytourism.com, 11 eec.ky.gov, 11 none) (A, opened the files)
- **KDFWR (129 places):** 146 files on `fw.ky.gov/More/Documents/<Name>…pdf` plus 127 online images `app.fw.ky.gov/kfwis/Map_Images/<Name>Online_Image.jpg`; list/detail page `app.fw.ky.gov/Public_Lands_Search/detail.aspx?Kdfwr_id=<N>`. My guessed pattern holds, but the ending is NOT fixed: `_ALL` 73, `_All` 28, `_all` 9, `All` 5, `ALL` 2, `all` 2, other 27. So a bot must READ the saved link, never build the name. Map dates are on the map itself (Kentucky Lake WMA: 11/18/2016); the saved list has no dates. The HQ file's link for this one was not re-opened by me; dead or older links: not tested (BOT LOOK-UP: HEAD-check all 146 and read the printed date of 10 samples).
- **Kentucky State Parks (49 places):** every map is on kentuckytourism.com: `www.kentuckytourism.com/media/docs/default-source/listing-documents/<kind>-map[<guid>].pdf?sfvrsn=<hex>_2` (kinds: Park Map 41, Campground Map 26, Trail Map(s) 5, plus a bison fact sheet and tour papers that are NOT maps). The generic name `park-map.pdf` is shared; a long GUID in the name makes it unique, so the `sfvrsn=` tail is the version marker (it changes when the file is replaced = best map-date hint). Handover check: Otter Creek is a Meade County matter (HQ note), not seen in these links.
