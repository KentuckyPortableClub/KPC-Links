# Check the pin: parks whose official outline is found by name but the POTA pin sits outside it

Chat 2, Oct 29 2026 (from the clue search, chat 8's 'worth a pin look'). Rule B9: an alias joins only with the POTA pin inside, and chat 8 ruled 'no hand join outside the pin rule'. So these stay pin-only until a person opens POTA's map + the agency map: if POTA's pin is simply off the land, the fix is to report it to POTA (or Brandon rules a hand join). 'km' = pin to the middle of the layer's outline (a big forest's middle can be far from a pin near its edge).
