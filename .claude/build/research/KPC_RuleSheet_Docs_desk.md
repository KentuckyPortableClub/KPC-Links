# OFFICIAL-DOCUMENTS BOT RULE SHEET: breaking it (chat 8 desk, Oct 28 2026)
Sheet under test: mapping.md, 'OFFICIAL-DOCUMENTS BOT built (chat 2, Oct 28 ~1:40 AM)', rules (1)-(7) + manners. Real cases are from the OFFICIAL_MAPS survey. LEAN = what I would rule; Brandon decides.

## A. Rule conflicts (the sheet contradicts itself or the real web)
**A1. Rule (2) 'anything off the agency's site is not a map' kills Kentucky State Parks.** Their official map PDFs live on kentuckytourism.com (/media/docs/default-source/listing-documents/...), a state tourism host, linked from parks.ky.gov. Same family: Ohio dam.assets.ohio.gov, NC ncwildlife.gov/media, Parks Victoria maps on store.avenza.com, QLD two host names (parks.qld.gov.au and parks.desi.qld.gov.au). The Kentucky FINDER check would fail on exactly the parks Brandon cares most about.
→ FIX: replace 'on the agency's site' with 'on a host the agency's own page links to, or a host of the same government (state domain, tourism or asset host)'. Record the host as `via`. Third-party hosts (Avenza, Gaia, AllTrails, Google) stay out unless the agency's page links them; then label 'via Avenza'.
**A2. 'PDF first' (rule 1) picks the OLDER map.** If a park has a 2016 PDF and a 2025 interactive viewer (ArcGIS), the PDF wins by kind order. LEAN: kind order is only a tie-break among maps of the SAME or unknown age; when dates are known and differ by more than 3 years, the newer wins and the older is kept as 'older copy'. Cards show one primary map + at most one 'newer interactive map' link.
**A3. Rule (4) last fallback 'the day we read it' as a map date.** It reads as 'map dated Oct 28'. LEAN: store as `date: null, date_how: 'unknown', checked: <day>`; the card says 'date unknown, checked <day>', never a date.
**A4. Rule (6) 'transferred/handed over' sentences are hints, never applied.** Levi Jackson (City of London, Sept 2019) and Otter Creek (Meade County, 2026): the state site may still host the old map and still name the state as the agency. The card would show the wrong operator with confidence. LEAN: if the park's page text or a news hint says transferred/closed to the old agency, status = 'handover suspected', map kept but marked 'may be out of date', nothing on a card until a person looks (it is not a grey area; it is the sheet's own 'unsure → nothing reaches a card').

## B. Edge cases that break a rule
1. **Brochure vs hunting map.** WMA/Game Land pages carry both. For a WMA the hunting/area map IS the boundary map; for a state park the brochure/park map is. A park page that lists 'Park Map', 'Hunting Map', 'Trail Guide', 'Accessibility Guide' gives the bot 4 PDFs. LEAN: rank by keywords, per park type: park types: park map > brochure/visitor guide > trail map; WMA/game land types: area map > hunting map > brochure; record all, `kind` of each, primary = highest rank. Never let a hunting map stand for a state park.
2. **Tourism site copy vs the agency's own.** If both exist, the agency's wins, but only if it is the same edition: a tourism copy dated newer beats an agency copy dated older (A2 logic). Record both `url`s, primary = newer; tie → agency.
3. **Map for a different unit.** (a) Region overview ('Southern Inland Queensland parks and forests map' on Crows Nest's page); (b) a combined map for several units (MO 'Wallace_Odowd_Trimble'; KY WMA multi-unit PDFs); (c) a sister park's map linked as 'nearby'. LEAN: the first page text must contain the park's name (or its alias list); (a) kind = 'region overview' and never primary if a park-specific map exists; (b) accepted, flagged `covers: N units`; (c) rejected by the name test.
4. **PDF with no date.** Common (BC, Manitoba, Ontario all show none). Rules 4 already allows it; see A3. Also a PDF with only '© 2019' (base-map copyright, template year) must not be called 'dated 2019'.
5. **Date strength order is wrong in one place.** Rule 4 lists '© year' next to 'Date Published'. LEAN: rank: printed 'published/revised/updated' date > printed month+year (footer code like '2310 / Jun 2021', seen on Forestry England) > PDF metadata CreationDate/ModDate (often the print shop's, can be later than the map) > upload folder 'YYYY-MM' (this is when it was POSTED: label 'posted') > year in the file name > '© year' > server Last-Modified (CDN and redeploys reset it; weakest) > unknown. The `date_how` always says which.
6. **Ambiguous date formats.** Ohio's 'Date Published: 5/3/2022' = May 3 (US). Outside the US the same string is 5 March. LEAN: parse by country; if day ≤ 12 and country not US/CA → store `date_how: 'printed, day/month order assumed'`.
7. **Cache/version strings are not dates** (`sfvrsn`, `rev`, `hash`, Hash-in-path). The sheet should say so explicitly (survey found them in KY State Parks, CT, MI).
8. **A map PAGE that links many PDFs** (rule 1 'the PDF is the map and the page is its source'): which PDF? See B1. Also ArcGIS web-app link (BC Parks, Alberta) = 'interactive map', accepted as the map only when no PDF exists.
9. **Soft failures.** HTTP 200 for a 'page not found' HTML, a login wall, or a PDF of another year after a redesign. LEAN: require the PDF magic bytes (%PDF) or an image content-type, and the name test (B3) on page 1; otherwise status 'opened, wrong thing'.
10. **Campground/lodge/golf maps are scored down** but at Corps lakes and some recreation areas the campground map is the only map. LEAN: accept as `kind: campground map` when nothing better, labelled; never as 'park map'.
11. **Two agencies, one park** (Corps land leased to a state park; USFS land with a state-run rec area; 2-fer neighbours). LEAN: record every agency map found with its agency; primary = the agency that manages the visitor facilities; flag `two agencies`.
12. **Language.** Quebec ('carte', 'plan'), Spain ('mapa', 'plano'), Germany ('Karte', 'Lageplan'), France, Italy ('mappa', 'cartina'), Norway ('kart'), Poland ('mapa'), Japan ('地図', '案内図'). The rule says 'text/address says map/brochure/trail guide'; for Canada east and the world the keyword list must be per language. Not a US problem; needed before the world run.
13. **Rules pages.** 'rules/regulations/permits' (rule 5): a 'permits' link is usually a fee/permit purchase page, not rules. LEAN: drop 'permits' unless the text also says rules/regulations; hunting-regulation digests are not park rules (label 'hunting regulations'). Federal patterns (Compendium, forest orders, refuge rules) are kept only if OPENED; add a content check that the page is not the agency home.
14. **'Checked <30 days ago is skipped'** means a map replaced two weeks after a check stays stale up to 30 days; accept, but re-check on a park the nightly bot flags (closure, handover hint) regardless.
15. **robots.txt obeyed, no exemption.** Fine. Cost: sites that disallow bots (some state sites; NASA, per earlier errors) land in 'needs a person/browser'; the review file should count them separately so a low score is not read as 'no maps online'.
16. **Kind labels for NPS:** the Unigrid 'brochure' contains the map; an NPS 'brochure' PDF is the official map. Accept; `kind: brochure (contains map)`.

## C. Grey areas (my lean; Brandon rules)
| # | Question | Lean |
|---|---|---|
| D1 | Is a tourism-department or asset-host copy 'official'? | Yes, when the agency's own page links it or the host is the same government. Label the host. |
| D2 | Newer interactive map vs older PDF: which is 'the official map'? | The newer one; keep the PDF as 'printable copy' if the viewer has no print. |
| D3 | May a campground-only map stand in? | Yes, labelled, only when nothing else. |
| D4 | Combined multi-unit map? | Yes, labelled 'covers N units'. |
| D5 | Region/overview map? | Never primary when a park map exists; otherwise 'overview map', labelled. |
| D6 | Map with no date? | Yes, shown as 'date unknown'; may not be called current. |
| D7 | A map more than 5 years old? | Shown with its date and 'check it is still current' wording; never hidden. |
| D8 | Hunting map as a park's map (WMA)? | Yes for WMAs/game lands; no for state parks. |
| D9 | Agency changed (handover)? | Hold off the card; a person decides; show the new operator's page if found. |
| D10 | Third-party host with the agency's content (Avenza, Gaia)? | Only via the agency's own link, labelled. |
| D11 | Two official maps, equal age? | Show the one on the managing agency's own host; the other as 'also'. |

## D. How I will grade the bot's data/docs/review.md samples (12 parks per area)
