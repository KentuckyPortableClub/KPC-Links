2. **Public land:** **RMK (State Forest Management Centre) manages the state forest and runs the free recreation sites and hiking trails across the country** (B). No polygon layer opened; Estonia is the likeliest of the four to have an open RMK layer (C): ask.
3. **No outline (31):** State Recreation Site 65 (61 none): Abula telkimisala EE-0079, Diby puhkekoht EE-0081 (RMK camping/recreation sites: points); State Recreation Area 13 (12 none): Haanja–Karula EE-0023, Räpina–Värska EE-0024 (RMK recreation areas = state forest: public land if layer); State Trail 4 (all none): Oandu–Aegviidu–Ikla EE-0036, Peraküla–Aegviidu–Ähijärve EE-0037 (RMK hiking trails: lines); World Heritage 2 (Tallinn Old Town EE-0077, Struve Arc EE-0078: pin); Hiiumaa Islets Landscape Reserve EE-0010.
4. **Sea/lake:** Islets, Matsalu Bay, Peipus: water-only.
5. **Grey:** W25-1: RMK recreation sites = points, no 2-fer test; recreation areas = public state forest (lean count).
