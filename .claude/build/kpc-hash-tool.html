KPC member-password hash tool

This page runs only in your own browser. Your password is never sent anywhere — it stays on this device the whole time, even offline. Type the member password once and copy the result back to Claude in chat; the result (the "hash") cannot be turned back into your password.

Open this file by itself (double-click it, or File → Open in your browser) — it does not need to be online. Delete it from your downloads when you're done, if you like; it holds no secret of its own.
