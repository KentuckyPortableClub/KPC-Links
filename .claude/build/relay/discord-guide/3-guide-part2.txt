**⏰ LATER (Kentucky / Central time)**
Start with **Post** (or **Schedule**), then the day and time:

`Post Oct 20 8am:`
`Post Oct 20 8:30 pm:`
`Post October 20 at 6:30 pm:`
`Post 10/20 8pm:`
`Post 10/20/2026 7am:`
`Post Saturday 7am:`
`Post tomorrow noon:`
`Post 3pm:`  (today, or tomorrow if 3 PM has passed)
`Post Oct 20:`  (no time = 8 AM)

Add places too: `Post Friday 6pm + All:`
Shows ⏰ while it waits. Delete it to cancel. Edit it to change the time.
