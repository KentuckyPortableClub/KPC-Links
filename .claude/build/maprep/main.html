POTA PARK ADDITIONS · ANY STATE

Mapping Representative's Tool Box

Type a park's name (add the town and state to narrow it down). It finds the land in the national public land database, checks it against POTA's rules for adding a park, and gives a yes, no or check-it-yourself for each rule, with the official links and a boundary map.

Private page. Not on the menu or in search. Share the link only with people who need it.

The rules come from POTA's "Park Additions and Edits" page (docs.pota.app). The database answers what it can (owner, manager, public access, size, other parks around it); the yellow items are ones only you can confirm, like the official web page and the way in. This is a helper, not a decision: the state's Map Rep decides.
